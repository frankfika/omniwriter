# 四期实施方案（把关后）

## 0. 裁决结果

**先说结论：WP-B 按你现在的写法会出问题。** 你说"两个组件给公众号渲染的是同一份 HTML"，这一条我核实后不成立，有两处不对：

1. **用的数据不是同一份。** `PreviewPane` 渲染的是 `selectedContent`，也就是**现在的原稿**（`page.tsx:928`，来自 `article.content`）。`PlatformTabs` 公众号 tab 渲染的是 `article.platformDrafts.wechat`，这是批量生成那一刻存下的**原稿副本**（`page.tsx:327`、`page.tsx:592`）。由此会出三种情况：
   - 用户之后改了原稿，公众号 tab 显示的还是旧稿。
   - 导入素材（`materialType='copy'`，`page.tsx:232`）时没有平台稿，公众号 tab 只会显示"还没有公众号文案"。
   - 选的平台里没有公众号（比如 `dev` 预设：X/HN/Reddit/CSDN），`PlatformTabs` 里**根本没有公众号 tab**，成品预览就整个找不到了。
2. **渲染函数也不一样。** `PlatformTabs` 只在复制时（`onCopy`，`PlatformTabs.tsx:65`）用 `wechatBody()`。预览走的是 `applyInlineStyles(markdownToInlineHtml(...))`（`PlatformTabs.tsx:227`），不带模板、眉题和署名，所以预览和复制出来的效果本来就对不上。

**问题 1：PreviewPane 删除还是复用？选 C 的变体：PreviewPane 原样保留，作为固定 tab 放进 PlatformTabs。**
- 方案 B 要把大约 150 行代码（模板选择、长图、语言切换、复制）复制进 `PlatformBody`，而且还要把数据源从平台稿改成原稿，改动大，也容易改错。
- 方案 C 的变体：`PlatformTabs` 新增一个 `wechatPreview?: React.ReactNode` 参数。传了这个参数时，公众号 tab 固定排第一位，**不管 `brief.platforms` 选没选公众号**，内容就是 `<PreviewPane>`，跟着原稿实时更新。这样耦合只有一个插槽参数。顺带解决了上面"旧稿"和"预览与复制不一致"两个问题。

**问题 2：默认停在哪个 tab？默认公众号，但要能指定。** 把 `publishView: 'preview'|'platforms'` 换成 `publishTab: PlatformId`，并把 `PlatformTabs` 的 tab 改为由页面控制。改法几乎是逐行替换：
- 原来的 `setPublishView('preview')` 全部换成 `setPublishTab('wechat')`，共 5 处：`page.tsx:233/856/875/903/1044`。
- `runPlatformBatch` 里的 `setPublishView('platforms')`（`page.tsx:299`）换成 `setPublishTab(targets[0])`。否则用户说"生成小红书"，打开发布包看到的却是公众号，这是退步。

**问题 3：WP-D 和 WP-E 进不进四期？**
- **WP-D 不做**，同意你的判断。
- **WP-E 先纠正一个前提。** 侧边栏是 `hidden xl:flex`（`AppShell.tsx:78`），手机上根本不显示，所以"手机上 hover 不出来"这件事不存在。真正的问题有两个：
  - 屏幕宽度 ≥1280 的触屏设备（比如 iPad Pro 横屏）。这个改一个 class 就能解决，放进 WP-A 一起做。
  - **手机上没有任何入口打开历史文章。** 这比删除按钮更重要，记入五期，和移动端导航一起做。左滑删除、长按删除都不做。

**其他调整：**
- WP-A 的注释错得比你写的还多。两处注释都说"done 时按 `updatedAt` 重挂"，但非生成状态下的 Editor 实际是 `key={article.id}`（`page.tsx:1086`）。另外，你写的是"3 处"，但只列了 2 处。
- WP-A 原定的验收命令没有意义：`grep "残|待清"` 现在本来就搜不到（唯一一处命中在 `AgentConfigDialog.tsx`，和这里无关）。下面换成具体的检查。
- WP-C 核实成立：`GenerationProgress.tsx:22` 已写明 preview 数据源删除，`route.ts` 也没有 `slice(-1500)` 了。可以直接关闭。
- `generationProgress` 不是遗留代码，同意不动。
