## Round 6 修复

### 🔴 P0 编辑器图片粘贴 → store 不更新
Tiptap 的 `view.dispatch(tr)` 在 useEditor 的 onUpdate 回调里**可能**延迟一拍
（异步插入 + 同步派发）。仅靠 onUpdate 在某些时序下不触发 → store 永远停在原值，
下次 hydrate 之后图片丢失。

修复：
- `insertImageFile(view, file, at, onInserted?)` 新增 `onInserted` 回调
- `handlePaste` / `handleDrop` 在图片插入后显式同步把 view.dom.innerHTML 推给父组件
- 设 `pendingFromExternal = true` 防止 useEffect 把这个值当成「外部变化」再 setContent 一次

### 🟡 B1 标题输入框无法清空
`selectedTitle = extractContentTitle(selectedContent) ?? (language === 'zh' ? article.title : '')` —
清空输入框时 `extractContentTitle` 返回 null，受控 input 立刻弹回 article.title。

修复：
- `titleDraft` 本地 state + 失焦时 `updateSelectedTitle(draft)` + `setTitleDraft(null)`
- `selectedTitle = titleDraft ?? (extractContentTitle(...) ?? article.title)`
- useEffect deps = `[language, params.id, article?.title]`，不含 selectedContent
  （content 变化不该清掉 draft —— 用户敲字时 content 在变）
- 钩子放在 early-return **之前**（React 18 strict mode 下，hydrated/article
  状态切换会触发「Rendered more hooks」报错）

### 🟡 B3 图片插入正常路径双写
`onUpdate` 调 `onChange(editor.getHTML())`，显式 `onInserted` 又调
`onChange(view.dom.innerHTML)` —— 同一次插入写两遍 store。

修复：`lastOnUpdateAtRef` 记录最近 onUpdate 时间戳，`onInserted` 检查
`Date.now() - lastOnUpdateAtRef.current < 100` 就跳过 —— onUpdate 已覆盖的不重复写。

### O1 SSE done 分支依赖 React 18 自动 batching
`setContent` + `setLanguage('zh')` + `onTitle` 在同一事件回调里同步执行，
React 18 自动合并成一个 render。`window.history.replaceState` 仍会执行（不影响 React 渲染）。
加注释说明这个依赖。

## 开发实践
- **真实浏览器才能暴露 Tiptap 时序问题**：单测 mock `view.dispatch` 全过，但真实 Chrome 浏览器
  onUpdate 在异步 callback 里不触发。Playwright 真浏览器复现 → 加 onInserted 兜底。
- **React 18 strict mode 下钩子顺序必须稳定**：早期 return 后的 hooks 会触发「Rendered more hooks」。
  写完一个 useState 一定要搜全文确认所有分支都跑到这个钩子。
- **双模型评审覆盖**：codex 找到 B1（标题清空）+ B3（双写）+ B5（innerHTML vs getHTML）；
  claude 因 Token Plan 配额 429 拒答 —— 这种 fail-soft 模式可接受，codex 独立已经足够。
