# 2026-09-05 · OmniWriter UX 全局复盘（多 Agent 审计）

## 结论先行
工程硬功底扎实（store 防损坏 / AI 错误分级 / 平台字数硬上限 / 改稿图片不外泄），但 UX 层三大问题：
1. **跨组件状态不同步**：`useAiStatus` 不是全局单例、生成/改稿后强制重置 `language('zh')`、`AppShell` 在 hydration 期间已渲染旧文章列表。
2. **首页决策过载**：首屏同时露 WriterAgent × SCENE × 风格 × 平台四层选项，与"一句话→多平台"心智冲突。
3. **响应式小屏坑**：插入图片要 3 次原生 prompt、底部 safe-area、键盘遮挡、drawer 关闭等还需打磨。
