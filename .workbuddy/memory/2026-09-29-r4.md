## Round 4 修复（codex 评审 9 项，合并 8 项 + 跳过 1 项）

### 🔴 B4 — 备份漏写 custom Agents（最严重）
`createBackup` 只导 articles + config，备份里完全没碰 `omniwriter-custom-agents`。
用户换设备 → 自己孵化的写作流程全丢，其它备份恢复都没意义。

修复：
- `backup.ts`: `createBackup` 加 `customAgents: listCustomAgents()`
- `parseBackup` 加 `customAgents?` 字段（旧备份缺这个字段时不抛错）
- 新增 `validateCustomAgents` + `isCustomAgent` 校验器，非法条目静默跳过
- `settings`: `importBackup` 调 `restoreCustomAgents` 把备份里的 Agent 写回 localStorage
- settings 文案：「备份包含文章、平台稿、模板、创作偏好，以及你自己孵化的写作 Agent」
- 恢复成功消息附 Agent 数量

### 🔴 B1 — AgentStudio 双击「保存 Agent」产生重复
保存是 sync 的，但 `onClose` 关闭弹窗要走一拍；fast double-click 期间 React 还没
unmount，两次 `onSave` 都跑完 → 两条 id 不同的同名 Agent。

修复：加 `saving` 状态 + 防重复入口 + 按钮显示「保存中…」

### 🟡 B3 — discardCorrupt 顺序错
之前 `corruptRaw = null` 在 `saveAll` 之前；配额满写失败时，`corruptRaw` 已为 null
但损坏串还在 storage，下次 hydrate 又复现 banner。

修复：先 `saveAll` 成功再 `corruptRaw = null`，失败时 `set saveState='error'` 保留 banner

### 🟡 B5 — Settings 风格选择偷偷联动 marketStyleId
「默认风格」Select 同时写 voice 和 marketStyleId，UI 只显示「默认风格」。
用户在市场清掉「强制默认风格」后来这里挑一下，marketStyleId 又被悄悄设回去。

修复：只写 voice。marketStyleId 在市场里单独控制。

### 🟡 B2 — AgentStudio /api/agents/tune 缺 AbortController
关闭弹窗/卸载时飞行中的请求不取消 → 在 unmounted 组件上 setDirective。

修复：`tuneAbortRef` 在每次 callTune 前 abort 上一个、unmount cleanup abort 当前；
revise / trial 的 catch 把 AbortError 静默（用户主动关闭不是错误）

### 🟢 B7 — Settings 恢复备份无 in-flight 守卫
两次连点「恢复备份」会跑两次 `importBackup`，第二次的 `setBackupResult` 覆盖
第一次的成功/失败提示。

修复：加 `restoring` 状态、按钮 disabled + 「恢复中…」文案

### 🟢 B6 — Settings 缺「恢复默认」快捷按钮
只能逐个 Field 重置或导出备份后再恢复。

修复：Field 组件加可选 `onReset` prop（右上角「恢复默认」链接）；
默认风格 / 系列标题 / 作者署名 / 默认模板 / 两个 Eyebrow 都挂上；
默认发布平台改成 inline 「恢复默认」按钮

### 🟢 B8 — 备份恢复不调和 agentOverrides
备份里 agentOverrides 可能引用 builtin 已删除 / 自定义没恢复的 Agent。

修复：新增 `reconcileAgentOverrides(config, restoredCustomAgents)` —— 过滤掉指向
AGENTS ∪ restoredCustomAgents 之外的 override。settings 里顺序：
先 restoreCustomAgents 再 reconcileAgentOverrides，然后 saveConfig
