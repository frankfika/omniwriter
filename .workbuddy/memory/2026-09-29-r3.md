## Round 3 修复（Codex + Claude 双模型评审合并）

### 我自己（真实浏览器发现）
1. **`Editor.tsx` onUpdate → setContent 反流**：用户敲字过程中 AI 改稿回流，把刚敲的内容覆盖掉。
   - 加 `pendingFromExternal` ref 标记自写，下一帧 prop 变化跳过 setContent。

2. **`app/article/[id]/page.tsx` refine AbortError**：90s 超时或用户取消时把 'This operation was aborted' 直接抛给用户。
   - catch 中检测 `refineAbort.signal.aborted` 翻译成中文提示「改稿已停止，原稿没有变化」。

3. **`insertImageAtCursor` 错误兜底**：用户点了插入但 Tiptap schema 拒绝时静默 fallback 到文末。
   - catch 中除 console.error 之外调用 showError，用户能看到「图片无法在光标处插入，已附加到文末」。

### Claude（3 个独立发现）
4. **`src/lib/ai.ts` fallback 路径**：用户自带 key 失败时 attempt(undefined) 用空 key 再跑一次抛 'Missing API key' 混淆真问题。
   - 改成「只有用户没自带 key 时才切到服务端兜底」。

5. **`app/api/rewrite/route.ts` 4xx 状态码直传**：上游链接失效 / 推文删除时全 500 '洗稿失败'。
   - 改成「status 在 400-499 时直接透传」。

6. **`components/Editor.tsx` onUpdate/setContent 闭环**：同上 #1（重叠）。

### Codex（4 个独立发现）
7. **`src/lib/bilingual.ts` replaceContentTitle escape**：Markdown 分支 `# ${title}` 也没 escapeHtml，LLM 标题若含 `<script>` 经 markdownToInlineHtml 会变成真实 HTML。
   - 改成 `# ${escapeHtml(title)}`。

8. **`src/lib/bilingual.ts` extractContentTitle 未闭合围栏**：AI 流被截断时围栏里的 # 会被误判成标题。
   - collectCodeFenceRanges 同时收集「未闭合的 ``` 起点到文档末尾」。

## 二次评审的 4 个 bug（codex 单独跑）
- 🔴 **B1**: 取消 batch 后 `setAdapting` 卡死，所有后续平台适配按钮被 `adapting` 守卫挡掉，
  必须刷新页面。三道防线：onCancelPlatformBatch / onGenerate / runPlatformBatch early-return。
- 🟡 **B2**: extractContentTitle 空标题返回 '' 让标题输入框与 ValidationStrip 不一致。
  Markdown 分支用 `[ \t]+` 而非 `\s+`，避免吃掉行尾 \n 让 $ 跨过正文。
- 🟡 **B3**: replaceContentTitle 没复用 matchHeadingOutsideCode 跳过围栏/pre 的语义。
  统一用同一个 helper。
- 🟢 **B4**: onCancelGeneration 顺手 null 掉 controller ref，避免维护者误读。
